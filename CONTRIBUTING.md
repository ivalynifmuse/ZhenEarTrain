# Contributing

Thanks for your interest. This project is a dependency-free, single-file browser app.

- Keep the app usable without a build step or a backend.
- Keep user-selected audio and listening history local to the browser.
- Do not add Harman installer files, extracted media, or other copyrighted source material.
- Keep Simplified Chinese and English UI text in sync.
- Describe task-level settings as this project’s practice difficulty, not as official Harman ratings.

For substantial changes, open an issue first to discuss the proposed behavior. When submitting a pull request, include a short description and the browsers you manually checked.
